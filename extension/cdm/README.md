# CDM device folder

Drop your own Widevine **L3** `.wvd` device file here as `device.wvd` and the
extension loads it automatically on startup. You can also load one at runtime
from the Keyframe page ("Load .wvd…").

`.wvd` / `.prd` files are gitignored and must **never** be committed — they are
personal device credentials. This folder ships empty on purpose; bring your own.
